极简专注模式

类似掘金风格，标题和元信息紧凑排列在顶部，编辑器左右分栏实时预览

优点

  • 视线集中，写作专注
  • 实时预览反馈
  • 界面简洁清爽

缺点

  • 缺少封面/摘要编辑区
  • 元信息编辑不突出

三栏布局

类似 CSDN 风格，左侧设置面板 + 中间编辑 + 右侧预览

优点

  • 元信息编辑区独立
  • 封面/摘要编辑方便
  • 布局清晰分区

缺点

  • 三栏占用空间多
  • 小屏幕体验不佳
