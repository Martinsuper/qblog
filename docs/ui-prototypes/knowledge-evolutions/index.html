FIVE EVOLUTIONS · 2026-10

当前 UI 的五种走向。

五种演化都保留当前知识库界面的骨架：顶部导航 + 多级目录树 + 正文阅读区，使用与当前实现同一组 46 篇示例笔记。区别在视觉气质与少量交互增强，用来判断下一步把当前 UI 往哪个方向打磨。
01 / PAPER SERIF

纸感衬线阅读 ↗

暖纸底色配衬线正文，标题、正文与引用全部换成书卷气质；顶部有阅读进度条，右侧保留本页目录。适合长时间沉浸阅读。

02 / MIDNIGHT

墨夜暗色 ↗

当前双栏骨架的完整深色主题：夜间低刺激底色、蓝紫高光、暗色代码块；索引状态与 MCP 来源标签也做了暗色适配。

打开方案 →
03 / COLORFUL

清爽彩签 ↗

现代笔记应用气质：柔和渐变底、彩色目录标签、圆角卡片与玻璃拟态头部；侧栏和正文变成两张悬浮卡片，右下角浮动新建按钮。

打开方案 →
04 / MONO

极简等宽 ↗

工程文件浏览器的质感：细线框、等宽文件名、路径式面包屑、编号小节；顶部命令条（⌘K）可实际过滤全部笔记，底部有状态行。

打开方案 →
05 / DASHBOARD

管理仪表盘 ↗

最接近当前视觉的一版：目录树顶部新增「总览」，内容区在仪表盘与正文之间切换；统计卡、索引队列、最近更新、目录分布与标签云服务批量整理。
