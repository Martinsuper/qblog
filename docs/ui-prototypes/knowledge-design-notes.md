# 大量笔记知识库 · 最新原型方向

## 已确认需求

- 从博客改成笔记知识库，笔记数量可能非常多。
- MCP 能直接写入笔记，知识库为后续 AI 检索提供资料。
- 用户日常主要浏览和整理笔记，AI 问答不占据主界面。
- 是否对外开放、实际权限模型尚未确认；原型不代表该决策已完成。

## 已选定的统一多布局原型

最新入口为 `09-unified.html`，配套 `unified-themes.css`，两个文件需放在同一目录。

- 01 留白三栏、03 纸间卡片、06 笔记书架、07 目录知识库，共享一套笔记数据和操作逻辑。
- 默认使用 07 目录知识库；配色独立支持浅色、深色、跟随系统。
- 07 布局取消编辑按钮，标题和正文可直接点击编辑，停顿约 650ms 自动保存到当前浏览器，支持 Ctrl / ⌘ S；新建直接进入正文，不弹编辑窗口。其他布局保持原来的编辑操作。
- 当前直接编辑为轻量富文本原型，保存时转换为安全 Markdown；表格与代码块已验证保留，但复杂富文本与完整撤销历史需正式编辑器支持。
- 外观偏好与当前笔记保存至 `younote.unified.preferences.v1`。
- 示例笔记统一保存至 `younote.unified.notes.v1`；不会直接覆盖之前独立原型的数据。
- 布局切换保留当前笔记、筛选、目录和收藏，阅读位置在当前会话内尽量保持。
- 列表每页 12 篇；书架展示知识目录，笔记作为章节，而非每篇笔记一本书。
- 当前仍为 HTML 交互原型，尚未移植到 Vue 或接入真实 MCP、索引与后端。

## 上一轮两种布局

| 方向 | G：目录型知识库 | H：资料管理型知识库 |
| --- | --- | --- |
| 主任务 | 连续浏览与阅读 | 检索筛选与批量整理 |
| 主布局 | 多级目录 + 紧凑列表 + 正文 | 目录 + 资料表格 + 详情抽屉 |
| 归档方式 | 逐篇阅读后移动 | 多选后批量移动 |
| 来源信息 | 正文辅助信息 | 列表列字段与详情 |
| 适合阶段 | 阅读、理解与沉淀 | 批量处理新写入资料 |

正式产品可以合并为同一个知识库的“阅读视图 / 管理视图”，不需要做两个独立系统。

## 重要边界

- HTML 原型没有真实 MCP 连接，没有向后端写入数据。
- 来源、索引成功 / 待索引 / 失败为演示字段。
- 浏览器 localStorage 只用于原型体验，不是正式知识库的持久化方案。
- 示例数据不能验证海量笔记性能；正式实现需要服务端分页、目录聚合、后端筛选与检索，必要时采用虚拟列表。
- 写入与索引应独立：保存笔记后进入索引队列，失败可重试；不能以“已保存”代替“可检索”。

## MCP 写入后续实现建议（未实现）

- 为外部笔记携带稳定 external_id / source，支持幂等创建或更新。
- 有可靠目录映射时直接归档，无映射时进入收件箱；不必强制人工逐篇审批。
- 记录来源工具、更新时间和版本；保留人工整理的目录与外部内容更新之间的边界。
- 笔记内容、目录变更和索引任务分别维护状态。
- 根据实际开放方式定义 API Token 范围与读写权限，不默认给予 MCP 全库管理权限。
