开始使用

只需三步，就能让你的工具安全地访问工作区。

01 / CREATE

创建访问令牌

为令牌命名，并选择需要开放的功能和有效期。

02 / CONNECT

配置客户端

复制 MCP 地址和令牌，填入你使用的 AI 客户端。

03 / EXPLORE

测试并开始使用

在客户端测试连接，然后查看已授权的工具。

ⓘ　访问令牌仅在创建时完整显示一次。请妥善保存，并按用途分别创建。
