统一知识库 · 原型说明

这是独立运行的本地界面原型，不是已接入服务的知识库产品。所有初始内容均为人工编写的示例。

支持 01 留白三栏、03 纸间卡片、06 笔记书架、07 目录知识库四种布局，以及浅色 / 深色 / 跟随系统配色。布局共用一份笔记数据，切换保留当前笔记、筛选和会话内阅读位置，偏好与当前笔记在刷新后恢复。笔记列表每页 12 篇，书架显示知识目录而非单篇笔记。

包含 48 篇初始笔记。全文搜索覆盖标题、正文与标签；可组合目录、标签、来源筛选。收藏、编辑、新建和单篇移动保存在此浏览器的 localStorage。无账号、云同步或后台写入。

MCP 导入、工具名、更新记录、已索引 / 待索引 / 失败状态均为演示数据。本原型未连接 MCP、索引服务或 AI 模型，不执行真实问答。知识助手仅提供本地整理入口。

保存前会校验本地数据结构，正文以安全 Markdown 子集渲染，不执行 HTML、脚本或外链资源。浏览器禁用存储时将提示并保留当前会话修改。
