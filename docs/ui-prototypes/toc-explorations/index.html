FIVE TOC PATTERNS · 2026-10

让目录长在文章里。

五个替代「白色悬浮卡」的目录形态，都保留同一篇文章与相同的交互：滚动自动高亮当前小节、点击跳转、目录过长时独立滚动。区别在视觉融入方式 —— 从「完全隐形」到「排进页边」，看哪一种和正文的联系最自然。
01 / QUIET RAIL

无框融入 推荐

去掉卡片的边框、底色和投影，目录就是页面边缘的一列安静文字，与正文共用字号与灰阶；当前小节用蓝色加左侧指示条标记。割裂感最低的常规方案。

02 / PROGRESS TRACK

进度轨道

右缘一条细线加章节圆点，像页面自带的滚动进度仪；只有当前小节浮现文字，悬停任意圆点可预览标题。存在感最低，适合长文沉浸阅读。

打开方案 →
03 / INLINE CARD

文首内嵌目录

目录作为文章开头的一张内嵌卡（可折叠、双栏编号），右侧完全不占空间，正文满宽阅读；卡头实时显示「正在阅读：xx」，顶部有阅读进度条。与文章浑然一体，代价是需要回头看目录。

04 / MARGIN NOTES

页边批注

编辑排版思路：目录文字右对齐悬在页边空白，一条细引导线指向正文，当前小节引导线加粗变蓝；暖纸底色与衬线标题，像一本打开的书。书卷气最浓。

05 / HOVER RAIL

极简刻度 + 悬停展开

平时右缘只有一排小刻度，几乎察觉不到；鼠标靠近右缘时滑出完整目录面板，移开即收起。阅读零干扰、导航按需出现，交互感最强。
