# 知识库紧凑工作台

本次调整针对默认知识库布局（KnowledgeSeven），不改变笔记 API、自动保存协议以及其他备选布局。

## 已完成

- 顶栏只保留品牌、全局搜索和工作区菜单，移除重复路径和未配置的知识助手入口。
- 侧栏去掉 PRIVATE、存储说明和重复统计；目录筛选按需展开。
- 列表采用平铺条目，默认展示标题、单行摘要和更新时间；不展示占位摘要、重复来源及标签。
- 筛选与排序统一收纳；全局搜索、目录内搜索、标签和来源的活动条件始终可单独移除。
- 支持标准与紧凑密度，通过本地存储保存；存储不可用时仍可正常切换。
- 正文移除装饰眉题和重复属性；来源、版本、更新时间、字符数收入笔记信息。
- 移动、编辑标签、下载、信息及删除收入笔记操作菜单，收藏和专注保留快捷入口。
- 本文目录默认关闭，没有标题时不展示入口或空目录。
- 保留自动保存状态、保存失败重试和版本冲突处理。
- 保留分栏拖动调整、折叠、全屏专注、右键操作和手机端区域切换。

## 真实后端联调补充

通过本地 `http://localhost:3001/blog/` 和运行中的 8081 后端，使用独立临时笔记完成：

- 标题与正文自动保存，并直接读取后端确认内容已持久化。
- 全局搜索、切换收件箱范围、正文目录展开与收起。
- Markdown 下载和操作菜单自动收起。
- 390×844 手机视口下打开笔记信息、关闭弹窗。
- 取消删除不影响笔记；确认删除清空正文并返回列表。
- 浏览器无脚本异常，测试临时笔记已清理，未修改已有笔记。

联调修复了选择笔记操作后弹出菜单未及时关闭的问题。

注意：开发后端默认 CORS 白名单为 `http://localhost:3001` 和 `http://localhost:3000`。用 `127.0.0.1:3001` 访问可能导致浏览器写入请求被拒绝（403），请使用 localhost；本轮未修改安全白名单。

真实接口联调未覆盖并发版本冲突、故障重试和全部目录管理流程；这些仍由现有单元测试部分覆盖，不应视为完整端到端验收。
