# 知识库状态反馈与键盘操作

## 已完成

- 默认知识库列表区分首次使用、空目录、空收件箱、无收藏和筛选无结果。
- 筛选无结果提供“清除搜索与筛选”；无收藏提供“查看全部笔记”，不再一律提示写第一篇笔记。
- 列表加载提供忙碌状态及读屏提示；加载失败显示重试入口。
- 打开笔记失败会捕获请求异常、保留当前笔记与草稿，提供“重试打开”和“返回当前笔记”。
- 空正文区提供新建入口，保存失败和版本冲突处理保持不变。
- 列表支持上下键、Home/End 移动焦点，Enter/空格沿用原生按钮行为。
- Shift+F10 打开笔记操作菜单，菜单支持上下键、Home/End，Esc 关闭并恢复原焦点。
- `/` 搜索快捷键不截获输入框、下拉框、按钮及弹窗内的键盘输入。

## 验证

- 前端 67 项测试通过，修改文件 ESLint 与生产构建通过。
- 浏览器连接本地真实后端读取已有笔记，未修改存储数据。
- 通过拦截指定 GET 请求模拟 503：验证正文打开失败仍保留原草稿，可返回或恢复网络后重试；列表失败可恢复后重试。
- 验证列表方向键、Shift+F10 菜单、Esc 返回焦点，以及无结果清除条件。
- 验证 390 像素宽手机列表空状态可操作且无横向溢出。
- 浏览器无脚本错误。首次使用等各类空场景另有纯函数测试，未清空真实数据库模拟。
