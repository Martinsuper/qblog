## 浏览器脚本

`frontend/tests/browser/settings-smoke.py`。

需要 Python Playwright 与 Chromium，先启动本地后端及前端（可使用生产 preview），再通过环境变量提供测试账号：

```sh
export QBLOG_TEST_USERNAME='<本地管理员用户名>'
export QBLOG_TEST_PASSWORD='<本地管理员密码>'
# 可选：QBLOG_TEST_FRONTEND，默认 http://localhost:3017/
# 可选：QBLOG_TEST_BACKEND，默认 http://localhost:8081
# 可选：QBLOG_TEST_CHROMIUM，指定 Chromium 可执行文件
python3 frontend/tests/browser/settings-smoke.py
```

仅允许 localhost/回环服务。登录后读取真实身份，浏览器 API 只转发 GET，禁止意外写操作；偏好仅写入临时浏览器上下文。
